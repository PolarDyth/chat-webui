## Goal

Flatten the chat thread into one clean, left-aligned block per exchange, and de-clutter the message UI. Today each exchange is staggered (question card pinned left/right alternating at `max-w-[85%]`, a connector line, then an answer card at `max-w-[92%]`) with a row of up to 5 bordered badges, a "YOU" label + token-estimate badge, and a card footer toolbar. Since no preference was given, going with the recommended flat-transcript style and plain background.

## Changes

**1. `src/components/chat/exchange-card.tsx` — rewrite as a flat block** (the core change)
- Remove the stagger: drop the `index` prop, `items-start/items-end` alternation, the two `Card` wrappers, `max-w-[85%]/[92%]`, and the vertical connector `<div>`.
- New structure, all flush left inside the existing `max-w-3xl` column:
  1. Question: plain text via `MessageResponse` with `text-sm font-medium` (no card, no "YOU" label, no `≈ N tok` badge)
  2. One thin muted metadata line (model · tokens · cost · duration) — see change 2
  3. Reasoning collapsible + markdown answer (unchanged behavior)
  4. Toolbar (copy / regenerate / model picker / branch selector) — reveal on hover: `opacity-0 transition-opacity group-hover:opacity-100 focus-within:opacity-100 [@media(pointer:coarse)]:opacity-100` so it stays usable on touch
- Preserve all behavior: `MessageBranch` wrapping (keep its explanatory comment), branch selector, streaming Shimmer, failed-turn state with Retry, memo wrapper.
- Update the component docstring ("card + connector" wording) and drop now-unused imports (`Card*`, `Badge`, `estimateTokens`/`formatTokens`).

**2. `src/components/chat/usage-badges.tsx` → rename to `usage-line.tsx`**
- Replace the 5 `Badge`s with a single `text-xs text-muted-foreground` line joined by `·` (model id truncated, token count, cost with in/out in `title`, duration). Fallback notice stays as amber text with its tooltip; streaming state stays as a small spinner + "answering…/routing via X…". No information is deleted — just de-boxed.

**3. `src/components/chat/chat-canvas.tsx`**
- Stop passing `index`; tighten exchange spacing `gap-10` → `gap-8`; remove the `canvas-grid` class.

**4. `src/components/chat/chat-workspace.tsx`**
- Remove `canvas-grid` from the landing; update the stale landing copy ("lives on its own card…" → describes the flat thread).

**5. `src/app/globals.css`**
- Delete `.canvas-grid` and `.canvas-grid-fade` (the fade is already unused anywhere).

No Next.js API surface is touched (all files are `'use client'` React/Tailwind), so no `node_modules/next/dist/docs` reading is needed; AGENTS.md stays untouched.
